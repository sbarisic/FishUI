# FishUI revision, 9 September 2026

This review covered the runtime, control hierarchy, input and focus, layouts, text editors, lists and grids, animations, rendering, theme loading, YAML integration, designer export, diagnostics, backend integration, and sample/test projects. The changes fix reproduced failures and related paths that shared the same defect. They do not establish that every possible input or platform is free of defects.

## Runtime and rendering

- Removing a root or child during an update no longer skips its next sibling. Initialization and layout traversal also use stable snapshots; unchanged control lists reuse their arrays.
- Blur callbacks can redirect focus without recursive blur calls or having their new focus overwritten. Focusing the same control no longer repeats its focus callback.
- Text callbacks can clear focus while input remains queued. Each subsequent character checks its target again, including after a text filter runs.
- Mouse release reaches the control that owned the press when the pointer leaves its bounds. Controls that detach during a press cannot regain pressed state from that dispatch.
- A resize failure during attachment detaches the incoming subtree before restoring its previous owner.
- Animation callbacks can remove or replace animations without updating another animation twice. Newly added animations wait for the next update, and a completed animation applies its final value once per update.
- List, textbox, grid, dropdown, and image clipping scopes unwind on drawing exceptions. A successfully begun graphics frame is ended even when drawing fails.

## Controls and layout

- Spreadsheet editors advance UTF-16 offsets correctly for supplementary characters and use grapheme boundaries for cursor movement and deletion. Stored values normalize malformed UTF-16.
- Spreadsheet Tab commits the edit and retains grid focus. Commit callbacks observe the completed edit state.
- DataGrid, ListBox, and ItemListbox prepare scrollbars and item geometry before input. Drawing no longer creates these controls or positions list widgets.
- Scrollbars in lists and grids map to the scrollable extent, rather than the full content height. Positions remain within the content after layout changes. Spreadsheet scrollbar geometry also respects UI scaling and the actual control size.
- DataGrid programmatic multiselection updates the selected-index collection. Fresh pointer clicks compute their row or header directly.
- Reverse flow starts with the first child at the far edge. Wrapped content measurement counts the first item on each new line correctly.
- Hidden stack children do not contribute spacing. Nonuniform grids measure each row and column separately, and stretched cells cannot acquire negative dimensions from insufficient space.
- Calendar rendering and navigation handle January of year 1 and December of year 9999 without DateTime overflow.
- Timeline synchronization retains a chart's manual view origin, and timeline track geometry is prepared before input.
- Reducing a chart's point capacity removes all excess points on the next insertion. Equal adjacent timestamps no longer produce a division by zero during interpolation.

## Theme, designer, and backend

- A child theme can explicitly disable an inherited atlas.
- Designer output escapes keyword identifiers, avoids its own generated member names, emits valid combined enum flags and nonfinite float literals, preserves nonrelative positions, and omits runtime children. Numeric ranges are set before values. Root enumerables are materialized once for the generator's multiple passes.
- Raylib window flags are configured before window creation. Framebuffer capture now copies the actual physical framebuffer; the former DPI expansion workaround cropped correctly configured high-DPI frames.

## Compatibility

`DockMode` now uses independent bits: `None = 0`, `Left = 1`, `Top = 2`, `Right = 4`, and `Bottom = 8`. Previously, the overlapping values made vertical docking affect horizontal geometry. Recompile callers that use these enum constants. Migrate any stored numeric dock masks; layouts that store enum names retain those names.

Mouse release now follows the press owner when one remains interactive. Custom controls that depended on release being delivered to a different hovered control should use their hover or drag handlers for that behavior.

## Validation

- Baseline: 245 UnitTest cases and one FishUI_UnitTest case passed.
- Added 30 regression cases in `UnitTest/RevisionRegressionTests.cs`, including failures reproduced before their fixes.
- Final Debug and Release solution tests: 275 UnitTest cases and one FishUI_UnitTest case passed in each configuration.
- Debug and Release solution builds include the .NET Standard 2.1 Unity source-compatibility project.
- A generated designer form was compiled and executed to verify numeric bounds/value, absolute position, combined flags, keyword and reserved-member IDs, and runtime child counts. The local harness is under the ignored `artifacts/revision-codegen` directory.
- Native Windows Raylib samples exercised DataGrid, DatePicker, ItemListbox, LayoutSystem, ListBox, SpreadsheetGrid, UI Scaling, and Diagnostic Snapshot. Diagnostic capture completed with screenshots and overlays. Both application-owned and backend-owned frame modes were exercised.
- Visual inspection at 125% display scaling caught the obsolete framebuffer workaround. After its removal, the SpreadsheetGrid capture retained the full frame and its title and headers.

Native sample checks cover startup, update, rendering, and capture. They do not replace a complete interactive acceptance pass. Unity editor/player, Linux, macOS, and a multi-monitor DPI matrix were not exercised.
